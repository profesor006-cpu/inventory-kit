# Inventory Kit

Biblioteca de Python para la gestión de inventarios con SQLite y el análisis de datos con Pandas.

## Funcionalidades

- Registro, edición y eliminación de productos.
- Gestión de entradas, salidas y ajustes de stock.
- Historial de movimientos.
- Consultas con filtros, proyecciones y ordenamiento.
- Operaciones individuales y múltiples.
- Análisis estadístico de inventarios.
- Procesamiento de datos desde SQLite, CSV, API y DataFrames.
- Aplicación de ejemplo con Streamlit.

## Tecnologías

- Python
- SQLite
- Pandas
- Requests
- Streamlit

## Instalación

pip install -e .
